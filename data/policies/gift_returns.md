# Gift Returns

Items received as a gift can be returned using the gift receipt included in the package, without revealing the price to the person returning it. Gift returns are issued as store credit rather than a refund to the original purchaser's payment method.

If there's no gift receipt, the item can still often be returned using the order number if the gift-giver shares it with you, subject to the standard Returns Policy window and conditions.

Gift-wrapped items must still meet the same return conditions (unused, undamaged, original packaging) as any other return.
